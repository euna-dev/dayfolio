# PRD — dayfolio

## 1. 제품 개요

| 항목 | 내용 |
|------|------|
| **제품명** | dayfolio |
| 형태 | PWA (모바일 설치형) |
| 플랫폼 | 웹 브라우저 + 홈화면 설치 |
| 저장 방식 | localStorage (Phase 1) → 서버 DB (Phase 3) |
| 인증 | 없음 (Phase 1) → 로그인 (Phase 3) |

### 제품 목표
매일 습관을 체크인하고, Bullet Journal 스타일의 Monthly Spread로 한 달을 시각적으로 추적하는 개인 습관 관리 앱.

---

## 2. 핵심 컨셉

### Today ↔ Monthly 연동
- 데이터는 하나, 뷰만 두 개
- Today에서 체크인 → Monthly Spread에 즉시 반영
- Monthly에서 지난 날짜 수정 → 해당 날짜 데이터 업데이트
- 오늘 날짜는 두 화면 모두에서 하이라이트

### 디자인 컨셉
Bullet Journal 노트에 쓴 로그 감성을 디지털로 재해석.
따뜻한 오프화이트 배경, 절제된 세리프 타이포그래피, 포레스트 그린 포인트.
"디지털인데 아날로그 같다"는 첫인상.

---

## 3. 사용자 스토리

- 매일 아침 Today 화면에서 습관을 빠르게 체크인할 수 있다
- 오늘 하루 가장 기억에 남는 한 문장을 메모할 수 있다
- 오늘의 기분(5단계)과 수면 시간을 기록할 수 있다
- Monthly Spread에서 이번 달 전체 습관 달성 현황을 한눈에 볼 수 있다
- 습관을 카테고리/태그로 분류해서 관리할 수 있다
- 주간/월간 통계와 습관별 달성률 (score %)를 확인할 수 있다
- 리마인더 알림을 시간대별로 설정할 수 있다

## 4. 화면 구성

### 4-1. `/` — Today (메인)

```
┌─────────────────────────────┐
│  April 1  │  [Monthly] →   │  ← 날짜/우측버튼 /monthly 이동
├─────────────────────────────┤
│  ✏ 오늘의 한 줄 메모        │  ← 인라인 편집
├─────────────────────────────┤
│  [카테고리 필터 태그]        │
├─────────────────────────────┤
│  ○ 이동                     │
│  ○ 독서          ●          │  ← 원형 버튼 탭으로 토글
│  ○ 명상                     │
│  ○ 물 2L         ●          │
├─────────────────────────────┤
│  기분  😞 😐 😊 😄 😁      │
│  수면  ────────  7h          │  ← 슬라이더
└─────────────────────────────┘
```

### 4-2. `/monthly` — Monthly Spread

```
◀ April 2026 ▶
──────────────────┬────────────────────────────────
  Daily Log       │  Habit Tracker
──────────────────────────────────────────────────
  01 · 산책완료   │  habit   1  2  3 ...  score
  02 · 힘찬 하루  │  이동    ● ● ●  ○      83%
  03 · 집중↑      │  독서    ● ● ○  ●      75%
  ...             │  명상    ● ○ ●  ●      67%
  [오늘 하이라이트│  [오늘 컬럼 하이라이트]
                  │──────────────────────────────
                  │  기분 이번주    수면 평균
──────────────────┴────────────────────────────────
```

모바일: 탭으로 전환 (Daily Log 탭 / Habits 탭)

### 4-3. `/stats` — 통계 대시보드

- 습관별 시간 달성률 및 차트
- 주간 달성률 추이 라인 차트
- 스트릭 현황 (현재 / 최고)
- 기분 & 수면 평균 추이

### 4-4. `/settings` — 설정

- 습관 관리 (CRUD)
- 카테고리 관리
- 리마인더 알림 설정
- 데이터 내보내기 (JSON)

## 5. 기능 범위 (Phase별)

### Phase 1 — MVP
- [ ] 습관 CRUD + 카테고리/태그 분류
- [ ] Today 체크인 (원형 버튼 토글)
- [ ] 오늘 텍스트 메모 (인라인 편집)
- [ ] 기분 / 수면 기록
- [ ] Monthly Spread 뷰 (양면 레이아웃)
- [ ] Today ↔ Monthly 연동
- [ ] 스트릭 자동 계산
- [ ] localStorage 퍼시스턴스
- [ ] PWA manifest + Service Worker 기본

### Phase 2 — 완성도
- [ ] 통계 & 대시보드 (`/stats`)
- [ ] Web Push 알림/리마인더
- [ ] Monthly 달 선택 (◀ ▶)
- [ ] 데이터 내보내기 (JSON)
- [ ] 오프라인 지원 강화

### Phase 3 — 확장
- [ ] 로그인 / 회원가입
- [ ] 서버 DB 연동
- [ ] 멀티 디바이스 동기화
